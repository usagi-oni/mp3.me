# mp3.me
mp3 music player for studying and finding new music!
Like it says above this is basically just a little player with music from friends or that I myself enjoy. I wanted to make one of those lo-fi study things because well, I love music and it's gotten me through many semesters and hard times. I also wanted to explore different types of music so I did ask  around and see what my friends and even coworkers enjoyed and added some of their own tastes to my little project. I like to think that I added a bit of love for my friends on to the site. I mostly used visual studio code, github, many different websites and youtube videos while also using some AI tools like ChatGBT to help me learn java and correct any errors. I also had to download a java extension to visual code in order to be able to even have java function on there.
