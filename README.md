# mp3.me
mp3 music player for studying and finding new music!
Like it says above this is basically just a little player with music from friends or that I myself enjoy. I wanted to make one of those lo-fi study things because well, I love music and it's gotten me through many semesters and hard times. I also wanted to explore different types of music so I did ask  around and see what my friends and even coworkers enjoyed and added some of their own tastes to my little project. I like to think that I added a bit of love for my friends on to the site. I mostly used visual studio code, github, many different websites and youtube videos while also using some AI tools like ChatGBT to help me learn java and correct any errors. I also had to download a java extension to visual code in order to be able to even have java function on there. If I would start over I would first focus on myself and my motivation. I struggled a lot this semester but in all honesty I'm surprised I even finished this. I mean I'm really really glad I did but I feel like I could have done so much more if I would have focused harder. At least I really did put in a lot of effort in trying to learn and finish the project. Second, I would like to learn how to sync the audio to the actual visualizer bars so it looks smoother and nicer when I play. I tried so many times to get this function to work to the point where I was just getting annoyed while looking at my screen. It honestly burnt me out so bad but I think I need to learn more advanced java in order to correctly add that function. I would also work on organizing my code better because I feel like it looks messy but I'm not too sure if that's from the frustration of looking at it for long or just trying everything I can to look good but I got it to work so yay! I learned that visualizers are a pain to make and that every little correction can completely affect the code. I don't think I've struggled this hard on any of my sites but I did learn how to code some java so something good did come out of this lol. Overall I'm proud of what I could make even if I was a little too ambitious.
